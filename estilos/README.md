# Estilos de la comunidad / Community styles

Aquí se comparten configuraciones de VideoLab: escenas, posiciones y temas listos
para usar. *Share your VideoLab setups here: scenes, layouts and themes, ready to use.*

## Usar uno / Use one

1. Descarga el `.json` del estilo que te guste.
2. En VideoLab: **Ajustes → Compartir estilo → IMPORTAR**.
3. Antes de aplicar nada te dirá qué trae y **qué archivos te faltan**.
4. Si faltan imágenes o sonidos, pídeselos a quien lo publicó y suéltalos en
   **Ajustes → Sonidos e imágenes**.

*Download the `.json`, then in VideoLab go to **Settings → Share style → IMPORT**.
It shows you what is inside and which media files you are missing before applying
anything. Drop any missing files into **Settings → Sounds and images**.*

Tus escenas actuales **no se pierden**: por defecto las del estilo entran al lado
con otro nombre, y siempre se guarda una copia antes.

*Your current scenes are safe: incoming scenes are added alongside yours by
default, and a backup is always saved first.*

## Publicar el tuyo / Share yours

1. En VideoLab: **Ajustes → Compartir estilo → EXPORTAR**.
2. Abre una *issue* en este repositorio con la etiqueta `estilo` y adjunta el
   `.json`, una captura y los archivos de medios que use (o un enlace a ellos).

*Export from **Settings → Share style → EXPORT**, then open an issue tagged
`estilo` with the `.json`, a screenshot, and the media files it uses.*

### Por qué los medios van aparte / Why media is separate

Un archivo de estilo pesa unos **20 KB**; los GIF y sonidos que usa pueden sumar
**decenas de MB**. Separarlos hace que el estilo se comparta por chat sin pensarlo,
y el importador te dice exactamente qué archivos pedir.

*A style file is ~20 KB while its GIFs and sounds can add up to tens of MB.
Keeping them apart means a style travels over chat effortlessly, and the importer
tells you exactly which files to ask for.*
